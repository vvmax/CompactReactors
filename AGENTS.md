# Порядок работы
В начале каждой задачи найти актуальную общую базу https://github.com/vvmax/Sigmarix (обычно /workspace/Sigmarix). Проверить GitHub через tools/read-context.sh <owner/repo> [visual], прочитать её AGENTS.md, docs/preferences.md, docs/projects.md и сводку проекта. Затем прочитать этот AGENTS.md и docs/PROJECT_STATE.md, инструкции вложенных каталогов. Для визуальных задач прочитать docs/visual-guidelines.md и подходящие доступные референсы общей базы и исходный мод. Если база недоступна, использовать локальные сведения и сообщить ограничение.
Сохранять исходные версии инструментов и зависимостей; команды брать из состояния проекта. После существенных изменений обновить docs/PROJECT_STATE.md и краткую сводку в Sigmarix, коммитить и отправлять обе части в GitHub. Чужие обновления объединять по смыслу; force push запрещён. Не объявлять память обновлённой до push. Не хранить секреты и логи.

Этот проект: vvmax/CompactReactors. Версии и команды: docs/PROJECT_STATE.md.
