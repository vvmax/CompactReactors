# CompactReactors 0.4.1 — Minecraft 1.7.10

First GitHub release of CompactReactors, an addon that places a real Big Reactors reactor inside a single block. BigReactors performs the native structure validation, heat, fuel and RF calculations.

## Features

- Build reactor layouts layer by layer using real components from your inventory.
- Expand the standard reactor to 5×5×5, 7×7×7 or 9×9×9 with expansion modules.
- Configure an advanced reactor's width, height and depth independently. Maximums are configurable, up to the technical limit of 64 per axis; BigReactors limits also apply.
- View whole layers up to 10×10 and use pages for larger layouts.
- Browse coolant icons, coefficients and descriptions, with unavailable materials hidden.
- Pour multiple coolant cells from portable tanks, dismantle layouts quickly and recover their contents.
- Transfer RF, fuel and waste through the compact reactor block.

## Changes in 0.4.1

- Added item icons to the structural block guide.
- Added recovery of coolant portions into portable tanks from the player inventory in the reactor GUI.
- Added right-click pouring into placed Forge fluid tanks; sneak-right-click transfers multiple portions.
- Added a portion + empty bucket crafting recipe when a compatible fluid bucket is registered.
- Added item tooltips explaining recovery. Transfers preserve fluid data and leave whole portions untouched when a tank cannot accept another 1000 mB.

## Requirements and installation

- Minecraft **1.7.10**, Forge **10.13.4.1614**, **Java 8**.
- BigReactors **0.4.3A** and CoFHCore **3.1.4-329**.
- Place `CompactReactors-1.7.10-0.4.1.jar` in the `mods` folder on both client and server. Remove an older CompactReactors JAR first.
- Dependencies are separate downloads and are not bundled in this release.

`CompactReactors-1.7.10-0.4.1-source.zip` contains the source project and build wrapper. Build with JDK 17 for Gradle and a Java 8 toolchain, following the README.

## Validation and limitations

The Gradle build and automated checks passed on **18 October 2026**. They cover layout boundaries and migration, large dimensions and paging, NBT preservation, coolant catalog transfer, bulk pouring and recovery, bucket recipes, modules and model geometry. The release JAR targets Java 8.

Full in-game validation of the latest GUI/rendering, multiplayer and world/chunk behavior remains pending. Only passive RF reactors are supported; active steam cooling and turbines are not included.

SHA-256 checksums for the JAR and source archive are provided in `SHA256SUMS-0.4.1.txt`.
