# CompactReactors: состояние
Дата обновления: 18.10.2026. Основание: README, build.gradle, исходники и локальная сборка; базовый коммит [76e67ca](https://github.com/vvmax/CompactReactors/commit/76e67ca).
## Реализовано
Minecraft 1.7.10, BigReactors 0.4.3A, CoFHCore. Версия 0.4.1. Настоящий мультиблок BigReactors строится в служебном измерении; собственной формулы генерации нет. Обычный блок 5/7/9 с модулями, продвинутый — независимые X/Y/Z, по умолчанию максимум 32, технически 64. Редактор слоёв, страницы 10×10, топливо/отходы, RF, справочники, заливка и возврат жидкостей.
Архитектура: ReactorTile — состояние; NativeReactor — интеграция BR; PocketLayout/Ids/Provider — служебное измерение; ReactorGui/ScreenLayout/Container и MachineButton — интерфейс; ReactorRenderer — модель; LiquidCoolants/CoolantCell/Catalog — жидкости и справочник. Перед изменением уточнять конкретные классы по исходникам.
## Сборка
`python3 tools/download_dependencies.py`, затем `JAVA_HOME=/workspace/minecraft-1.7.10/tools/jdk17 bash ./gradlew build`. Wrapper 8.8, RFG 1.4.1 (архивный JAR), JDK17 для Gradle, Java8 toolchain для компиляции. При необходимости задать локально org.gradle.java.installations.paths; не заменять wrapper на mc-gradle 9.2 без отдельной задачи. Артефакт build/libs/CompactReactors-1.7.10-0.4.1.jar. Зависимости не включать внутрь JAR.
